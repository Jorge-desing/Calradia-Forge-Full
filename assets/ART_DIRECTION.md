# Heraldic Resonance

The ornament treats a mod ecosystem as interdependent lines: each curve is simple, but its intersections form a richer pattern. Two opposing sine waves establish a rhythm reminiscent of woven metal around a manuscript border.

The visual system reserves complexity for the margins. Carefully calibrated spacing keeps the center quiet, so diagnostic text remains the dominant information. Brass against dark brown connects the external workbench to the game's medieval setting.

Seed 148 fixes the small variations in the Gauntlet inlay. Reproducibility makes the artwork a build input rather than an incidental screenshot. The raster motif uses fixed mathematical phases and has no runtime animation.

The craftsmanship lies in restraint: aligned periods, symmetric intersections and a limited palette. The same geometry can be regenerated at different sizes without introducing an unrelated visual language. These resources are original and contain no extracted game art.

The release covers use the same brass and forest-green palette with a geometric anvil and shield. `tools/generate_release_art.py` produces English and Spanish static PNGs from seed 148. The English cover is the primary listing artwork; the Spanish cover is an optional localized variant.
