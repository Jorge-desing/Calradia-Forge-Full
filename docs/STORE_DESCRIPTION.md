# Calradia Forge — Verified Bannerlord Modding Tools

Calradia Forge is a developer-preview suite for Bannerlord Native 1.4.8. Diagnose a selected mod folder, inspect Forge session evidence and installed assembly metadata, build editable SDK starting points, register standalone Gauntlet extension pages, and verify retained ForgeWeave events through a guarded Replay Lab.

The mod does not require Harmony, MCM, ButterLib, or another runtime framework. ForgeWeave is an original cooperative event framework; it is not a promise of universal method interception or a replacement claim for tools that serve that different purpose.

Desktop file checks are truthful: supported local formats produce bounded file evidence; absent and unsupported inputs say **Not run** or **Unsupported**. Reports preserve analyzer identity, provenance, source file and line where available, severity, recommendation, limits, and raw evidence.

The in-game module adds a validated SDK catalog for standalone Gauntlet pages, offline contextual help, and static PE/.NET inspection with an opt-in preview/apply version copy. The asset workbench checks sprite metadata, part bounds and PNG header dimensions alongside limited TPAC presence/marker evidence. AsmResolver is included with both Modules and Desktop; DocFX runs only during documentation builds. Desktop keeps its three tactical themes, routed MVVM work orders, bounded evidence, and recent/favorite navigation. Downloads are separate: `CalradiaForge-Modules-22.0.0.zip`, `CalradiaForge-Source-SDK-22.0.0.zip`, and `CalradiaForge-Desktop-22.0.0.zip`. The Desktop archive has no app-host EXE and uses the .NET 8 Desktop Runtime.
