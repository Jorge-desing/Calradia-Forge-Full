# Recursos de iconos Gauntlet

Calradia Forge usa nueve SVG de Game-icons.net para el sello, la navegación, la búsqueda, el historial reciente y las tarjetas de contexto. Cada sección tiene un símbolo funcional: brújula para Resumen, engranajes para Módulos, pergamino para Registros, lupa para Inspector, espadas cruzadas para Pruebas, cronómetro para Rendimiento, martillo y engranaje para Framework y estandarte para Extensiones. `modules/CalradiaForge/GUI/SpriteParts/ATTRIBUTION.json` registra autor, página de origen, licencia y modificaciones de cada icono. Los SVG originales están en `modules/CalradiaForge/GUI/IconSources/GameIcons/`.

`tools/generate_game_icons.py` convierte los trazos SVG en geometrías WPF y PNG de origen de 128×128. Ejecuta `tools/Build-CalradiaForge-UiAssets.bat` para validar esas entradas y llamar a `TaleWorlds.TwoDimension.SpriteSheetGenerator.exe` instalado con Bannerlord para este módulo. Genera `GUI/CalradiaForgeSpriteData.xml` y `AssetSources/GauntletUI/ui_calradiaforge_1.png`; la categoría debe conservar `<AlwaysLoad />` desde `GUI/SpriteParts/Config.xml`. Define `BANNERLORD_EDITOR_DIR` con la ruta completa de `Win64_Shipping_wEditor` si el juego está fuera de la ubicación Steam predeterminada. El atlas de origen no es la textura de ejecución. Ejecuta `tools/Prepare-CalradiaForge-ResourceBrowser.bat` para validar y copiar solo el atlas y sus metadatos al módulo instalado. Si ya existen archivos distintos, guarda copias de respaldo con marca de tiempo; nunca copia el manifiesto ni las DLL. `--dry-run` muestra lo que haría y `--launch-editor` abre el Modding Kit solo si Bannerlord no está abierto. Si las versiones de origen e instalación difieren, avisa porque la herramienta solo prepara recursos estáticos y no actualiza el mod instalado. Después usa Resource Browser del Modding Kit para compilar el TPAC:

1. Inicia el Modding Kit instalado y activa Calradia Forge.
2. En el menú principal, abre la consola con `Alt` + `` ` `` y ejecuta `resource.show_resource_browser`.
3. Selecciona Calradia Forge, abre `Assets/GauntletUI`, busca archivos nuevos e importa `ui_calradiaforge_1.png` para `ui_calradiaforge`.
4. Confirma que exista `Assets/GauntletUI/ui_calradiaforge_1_tex.tpac` y ejecuta `tools/Prepare-CalradiaForge-ResourceBrowser.bat --collect-tpac` para copiarlo al módulo fuente. Reinicia el juego para actualizar la caché del atlas.

El espacio de trabajo y la instalación de Steam pueden tener versiones distintas de Calradia Forge. El preparador comprueba el ID del módulo e informa ambas versiones; una importación correcta de los sprites no equivale a actualizar el mod. Antes de copiar un TPAC al árbol fuente, la recolección usa `TpacTool.Lib` para leer su cabecera y los metadatos limitados de activos. Solo copia un paquete validado y guarda una copia fechada del archivo fuente anterior; no decodifica los datos de textura ni certifica el renderizado. El TPAC de 538 bytes incluido en 22.0.0 tiene una cabecera v2 plausible, pero el lector local no pudo leer el GUID de un activo. Por ello sus metadatos y el renderizado siguen sin verificarse; el error del parser no prueba que el archivo esté corrupto ni justifica una reimportación por sí solo.

Para carpetas grandes de fuentes, crea una orden de trabajo de inventario con `tools/Plan-CalradiaForge-AssetBatch.bat -SourceDirectory "C:\\AssetSources" -OutputJson "C:\\Reports\\asset-batch.json"`. El informe calcula hashes de candidatos, guarda rutas relativas y tamaños, identifica nombres base repetidos para revisión manual y separa las fuentes FBX/PSD documentadas y los PNG de generación de sprites de las extensiones no verificadas. Por defecto, limita el recorrido a 50.000 archivos, 50.000 directorios, 5 GiB de candidatos y 64 niveles; omite puntos de reanálisis. Guarda el JSON fuera del árbol de fuentes. Para reemplazar un informe existente usa `-Force`, que conserva un respaldo con fecha. El inventario completo termina con éxito; un recorrido parcial conserva un informe marcado `partial` y devuelve estado distinto de cero; al exceder un límite obligatorio no se escribe ningún informe. Este inventario es de solo lectura: no crea archivos `.meta`, no importa recursos, no ejecuta compiladores ni marca archivos como compilados. Un nombre base repetido requiere revisión, pero no demuestra una colisión del motor.

El esquema v4 añade `recommendedWorkflow`, `toolAvailability`, `atlasMappings`, duración acotada del planificador y una observación opcional del pico de memoria del proceso PowerShell. Comprueba si el ejecutable oficial de hojas de sprites y su biblioteca complementaria existen en `BANNERLORD_EDITOR_DIR` (o en la carpeta Steam predeterminada); pasa `-EditorDirectory "C:\\Program Files (x86)\\Steam\\steamapps\\common\\Mount & Blade II Bannerlord\\bin\\Win64_Shipping_wEditor"` para elegir otra instalación. Nunca inicia el generador. La generación aparece como `manual-run-ready` solo si existen ambos archivos y aun así requiere una consola visible e interactiva. Lee `GUI/*SpriteData.xml` con un límite de 4 MiB, DTD deshabilitado y resolución XML externa apagada. Las coincidencias de nombre de atlas/categoría/hoja son sugerencias para importar; una ruta TPAC predicha no prueba que Resource Browser la haya generado. La importación del atlas y la verificación del TPAC de ejecución siguen como `manual-required` o `not-attempted`; el planificador nunca las marca como completadas. La duración cubre inventario, hashes, lectura de `SpriteData` y mapeo. El pico de memoria cubre la vida del proceso PowerShell, no asignaciones por operación ni memoria del juego. Duración/memoria del generador, rendimiento del juego y reducción de cierres siguen como `not-measured`.

La infografía de arquitectura generada por IA no es una especificación de API. Sus ejemplos de edición `.meta` y `.fbs`, flags `/run_asset_compiler`, automatización con stdin redirigido e inyección de Roslyn en tiempo de ejecución no se implementan porque las interfaces documentadas o instaladas del proyecto no establecen esos contratos. Sus porcentajes, rendimiento, memoria y cifras de cierres no tienen evidencia de pruebas reproducibles y no se adoptan como mediciones de Calradia Forge. Consulta la [revisión de evidencia de automatización](ASSET_AUTOMATION_EVIDENCE.es.md) para ver el estado de cada afirmación.

El README generado dentro de `GUI/SpriteParts/` ahora explica que SpriteSheetGenerator solo crea el atlas y los metadatos; Resource Browser genera el TPAC de ejecución. La validación de recursos rechaza documentación que afirme que el paquete está listo sin comprobar su estructura y recuerda que ni el marcador `TPAC` ni la presencia del archivo bastan para aprobarlo.

Si falla la lectura de metadatos, el BAT de inspección muestra las rutas del módulo y del paquete, tamaño, conteo declarado, SHA-256, motivo del parser y el siguiente paso en Resource Browser. El BAT de recolección propaga ese diagnóstico y termina antes de modificar el paquete fuente. El fallo indica que el lector seleccionado no pudo verificar el paquete; no afirma por qué lo produjo Resource Browser.

```mermaid
flowchart LR
    A[Iconos SVG atribuidos] --> B[Generar atlas]
    B --> C[Preparar atlas y metadatos]
    C --> D[Importar en Resource Browser]
    D --> E[TPAC en el módulo de Steam]
    E --> F[Recoger TPAC al árbol fuente]

```

TpacTool es una ayuda opcional para inspeccionar el paquete después de generarlo. El ZIP Source-SDK no lo incluye. Para empaquetar, coloca la versión upstream en la carpeta `TpacTool` de la raíz del repositorio para que esté disponible `TpacTool/bin/TpacTool.Lib.dll`; el script de entrega se detiene si no puede realizar la verificación estructural. Ejecuta `tools/Inspect-CalradiaForge-Tpac.bat --validate-only`; la biblioteca local lee la cabecera y los metadatos de activos sin cargar los datos de textura. El comando completo solo abre el visor después de que el análisis estructural tenga éxito y muestra la carpeta que debes seleccionar en **File > Open AssetPackages Folder**. No decodifica la textura, verifica el aspecto del sprite ni garantiza compatibilidad entre versiones. La descarga local es la versión 0.4.0; el proyecto upstream la describe como visor/exportador e indica que todavía no implementa la creación ni la importación de paquetes. Esa versión se dirige a Bannerlord 1.8.0 beta; Calradia Forge apunta a 1.4.8, así que la compatibilidad sigue sin verificarse. Para importar, usa Resource Browser del Modding Kit. TpacTool es una herramienta local del usuario y no se copia a los ZIP. Su proyecto upstream tiene licencia MIT; consulta el [README](https://github.com/szszss/TpacTool#readme), las [versiones](https://github.com/szszss/TpacTool/releases) y la [licencia](https://github.com/szszss/TpacTool/blob/master/LICENSE).

Para inspeccionar el módulo instalado en la biblioteca Steam predeterminada, añade `--installed` al mismo comando BAT. Si Bannerlord está en otra ubicación, define primero `BANNERLORD_GAME_DIR`; la inspección sigue siendo de solo lectura.

Cuando ambas versiones tengan informes JSON de inventario aceptados por TpacTool, compara sus metadatos con `tools/Compare-CalradiaForge-TpacInventory.bat -BeforeReport before.inventory.json -AfterReport after.inventory.json`. La comparación empareja activos por GUID e informa conteos de agregados, eliminados, cambiados e iguales; `-IncludeUnchanged` muestra los conservados y `-OutputJson report.json` exporta el resultado. Los informes existentes requieren `-Force` y reciben una copia de respaldo con fecha. Las entradas permanecen intactas. Solo se comparan los metadatos reportados: la herramienta no vuelve a abrir los TPAC, no decodifica texturas, no comprueba que los informes aún coincidan con los hashes de origen ni confirma compatibilidad con el juego. Si un lector no acepta los metadatos, ese informe no se puede comparar; el fallo no demuestra que el TPAC esté corrupto.

La comparación conserva `createdUtc` de cada informe como `capturedUtc` en UTC, muestra las horas de captura anterior/posterior y la hora de comparación, y rechaza fechas inválidas o sin zona horaria. La fecha debe coincidir completamente con el formato ISO e incluir `Z` o un desplazamiento explícito `±HH:mm`; rechaza espacios/saltos finales y `-00:00`, que significa que el desplazamiento local es desconocido. Los desplazamientos se normalizan a UTC. El validador también comprueba campos anidados obligatorios, enteros sin signo con formato invariable, un arreglo JSON para los activos, el límite de 128 MiB del lector y que la tabla TPAC v2 declarada quepa después de su cabecera fija de 36 bytes. Así se ve la secuencia de snapshots alrededor de una importación en Resource Browser; no demuestra cuándo se modificó por última vez el TPAC subyacente, no vuelve a validar su hash ni autentica la procedencia del informe.

Para una auditoría local que deba ejecutar el lector de metadatos, usa `tests/CalradiaForge.TpacInventory.Tests.bat -RequireReader`. Este modo falla si falta el lector o el fixture Native, o si Windows bloquea el ensamblado; el modo normal informa `SKIP` para mantener la portabilidad. `-ToolDirectory "C:\lector-verificado\TpacTool\bin"` permite apuntar la prueba estricta a un directorio de lector verificado por separado.

El atlas de origen y los metadatos se pueden regenerar sin Resource Browser, pero el juego requiere el paquete de textura importado en tiempo de ejecución. El BAT solo informa éxito si el generador oficial termina normalmente y pasa la validación del origen; ejecútalo desde una consola visible porque la herramienta del juego espera una tecla al terminar. La auditoría de entrega exige por separado los recursos fuente y la textura compilada. Si RGL informa `Unable to find texture: ui_calradiaforge_1`, importa el atlas en Resource Browser, recoge el `.tpac` con `--collect-tpac` y reinicia el juego para que el gestor cargue el paquete.

Desktop incluye **Gauntlet Sprite Package Auditor** para revisar hojas de `SpriteData`, referencias y coordenadas de las piezas, rutas seguras y dimensiones IHDR de PNG fuente y atlas. Solo lee firma/cabecera PNG; no decodifica píxeles ni valida CRC. Para TPAC v2 comprueba la cabecera fija de 36 bytes, limita el conteo declarado a 1–100.000 y verifica que la tabla de contenido quede dentro del archivo. Las demás versiones se marcan como no compatibles con este análisis y no se leen con offsets v2. Una cabecera plausible es evidencia limitada: no analiza metadatos de activos ni datos de textura. El preflight BAT añade una lectura separada de metadatos con `TpacTool.Lib`. Usa TpacTool como visor/exportador de mejor esfuerzo y Resource Browser para importar en el juego.

El flujo oficial de Bannerlord descrito para este proyecto usa SpriteSheetGenerator y después Resource Browser. La inspección de los ensamblados administrados instalados y de la documentación oficial de importación no encontró una API pública documentada en C# para importar FBX por lotes ni un contrato de archivos `.meta` para controlar Resource Browser. Las convenciones `.meta` de otros motores no demuestran que Bannerlord las admita. Por eso el proyecto no genera sidecars especulativos ni afirma ofrecer un importador masivo de FBX/TPAC.
