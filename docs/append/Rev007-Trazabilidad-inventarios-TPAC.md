# Comparación auditable de inventarios TpacTool

Se mejoró el flujo de inventarios que acompaña la revisión de recursos importados mediante Resource Browser. Cada informe conserva la marca `createdUtc` y el comparador ahora la valida, la normaliza a UTC y la expone como `capturedUtc` en las ramas `before` y `after` del resultado JSON. La salida de `Compare-CalradiaForge-TpacInventory.bat` muestra ambas capturas y la hora de comparación para que el orden temporal de los snapshots sea visible.

Una marca de captura ausente o inválida detiene el diff con un error explícito. El formato ISO debe traer `Z` o un desplazamiento explícito `±HH:mm`; las horas con desplazamiento se convierten a UTC y una fecha parseable sin zona se rechaza en vez de suponerse UTC. La prueba compara inventarios con horas distintas, verifica la normalización `+02:00` a UTC, la conservación en la respuesta y el JSON exportado, comprueba las líneas de consola y rechaza fechas mal formadas. Esto aporta trazabilidad temporal; no vuelve a abrir los TPAC, no recalcula los hashes de origen ni demuestra cuándo se modificaron los paquetes originales.

El test local de inventario ahora admite `-ToolDirectory` y `-RequireReader`; su lanzador `.bat` reenvía esos argumentos. El modo normal conserva la salida portable `SKIP` cuando falta la instalación del juego/fixture o Windows bloquea el lector descargado. El modo estricto devuelve un error no exitoso si el lector o el fixture requerido no está disponible, evitando interpretar una omisión como validación completa. Se comprobó ese camino negativo con un directorio de lector ausente.

La prueba del comparador pasó mediante `tests/CalradiaForge.TpacInventoryCompare.Tests.bat`, incluida la validación de fechas, exportación, respaldos y protección contra sobrescritura. El test normal de inventario se ejecutó mediante su `.bat` y notificó `SKIP` porque Windows rechazó `TpacTool.Lib.dll` con `0x80131515`; por tanto, en esta ronda no se volvió a validar la lectura del paquete Native. El original descargado, sus marcas de procedencia, los TPAC de origen/Steam y los ZIP existentes permanecieron intactos; no se reconstruyeron distribuciones.
