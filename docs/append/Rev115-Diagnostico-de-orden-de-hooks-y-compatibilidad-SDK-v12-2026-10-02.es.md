# Rev115 — Diagnóstico de orden de hooks y compatibilidad binaria con SDK v12 — 02-10-2026

Este seguimiento agrega diagnóstico de solo lectura para el orden declarado de hooks. El registro normaliza los IDs sin prefijo y el formato `CalradiaForge.Hook.*` antes de rechazar ciclos entre hooks Forge registrados actualmente para el mismo método de destino exacto. `cf.hook_status` informa prioridad y metadatos `Before`/`After`; `cf.hook_order` clasifica las referencias frente al inventario Forge actual. Las referencias externas, ambiguas y a otros destinos quedan sin resolver. La salida describe declaraciones y no demuestra el orden efectivo de despacho de MonoMod.

Un consumidor binario desechable compilado contra el contrato de registro SDK v12 se cargó con SDK v13 y ejercitó las entradas antiguas de pruebas, comandos y proveedores. Este fixture cubre esas superficies de compatibilidad ejercitadas; no demuestra compatibilidad con todos los consumidores antiguos posibles. Las pruebas de ajustes ahora redirigen escrituras a una raíz temporal propia; los diagnósticos del guardado atómico incluyen el destino y el HRESULT, y los fallos de limpieza se informan sin ocultar fallos previos de pruebas.

La compilación Release de la solución terminó con cero advertencias y errores. La validación BAT pasó Core 413/413, el fixture serial x64 de detours/hooks, Desktop 65/65, ForgeWeave 73/73, render WPF con 295 casos y 308 pases de layout, aceptación stateless 4/4 y comprobaciones estructurales Gauntlet. La duración WPF pertenece al arnés de render y no mide la latencia interactiva de la aplicación. El fixture es serial y no demuestra seguridad cuando otro hilo ejecuta un destino durante una mutación.

Los callbacks Finalizer se intentan tras un fallo en Prefix/original/Postfix solo mientras permanezca abierto el gate de callbacks del anfitrión. Una transición de contexto o descarga del anfitrión puede suprimir el Finalizer; no es una garantía de limpieza incondicional. No se aplicaron hooks en Bannerlord en vivo. Se conservan el producto 25.2.0, la API Forge 13 y MonoMod.RuntimeDetour 25.3.6.
