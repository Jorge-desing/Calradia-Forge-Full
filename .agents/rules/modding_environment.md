# Bannerlord Modding Environment

- **Modkit Availability**: The Bannerlord Modkit is installed and available in the game's root directory. When tasks require official XML schemas, GUI prefab references, or mapping tools, assume the Modkit is accessible locally.

## External Documentation & References
When searching for modding documentation, C# API references, or XML schema definitions, consult the following community and official resources:
- **Official Modding Docs (Community Driven):** [Getting Started - Bannerlord Modding](https://docs.bannerlordmodding.com/_intro/getting-started.html#tools)
- **Nexus Mods Dev Updates:** [Nexus Mods News - Bannerlord](https://www.nexusmods.com/mountandblade2bannerlord/news/14378)

## Official Modding Kit Capabilities
The locally installed Bannerlord Modding Kit (launched via Steam with `Left Ctrl + E` on the main menu) provides the following toolsets which you can reference or ask the user to utilize when necessary:
- **Scene Editor:** Entity placement, Terrain/Heightmap sculpting, NavMesh generation, GI Baking, and Path Editing.
- **Resource Editors:** Material Editor (PBR tuning), Mesh & Texture Editors, Skeleton/Animation Viewer, Particle VFX Editor, Atmosphere Editor, and Physics/Cloth setup.
