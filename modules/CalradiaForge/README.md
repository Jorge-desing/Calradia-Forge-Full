# Calradia Forge 14.4.0 module

This folder is the standalone Bannerlord runtime module for Native 1.4.8. Copy it to `Mount & Blade II Bannerlord\Modules`, enable it after Native and SandBoxCore in the official launcher, then open Forge in a single-player session with **F10**.

The native panel automatically uses Bannerlord's active text language. It has no manual language switch. Forge has no compile-time or runtime dependency on Harmony, MCM, ButterLib, or another mod framework. `cf.patch_diagnostics` may observe a compatible patch runtime only when that runtime is already loaded; Forge does not bundle or load it.

ForgeWeave exposes controlled official lifecycle events, bounded evidence, failure isolation, quarantine, and guarded Replay Lab verification. It does not intercept arbitrary methods. State-changing test cases still require test mode and, for campaigns, an explicitly confirmed working copy.

The optional desktop application is a separate download: `CalradiaForge-Desktop-14.4.0.zip`. Do not copy its files into this module folder.
